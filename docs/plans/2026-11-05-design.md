以 https://www.czsrfloor.com/ 为视觉参考，保留 1200px 桌面内容宽度、蓝白配色、600px 轮播、分类产品横向展示、公司介绍、优势、工程展示、问题解答、需求表单及页脚的顺序。

技术：Astro 静态输出，原生 CSS 与少量原生 JavaScript，无 React 和旧站 jQuery；素材存储于 public，生产页面不请求参考站或统计服务。Logo 原样使用用户提供的 PNG，公司介绍完整使用用户提供的文本。所有企业陈述以用户提供资料为界；未知联系方式保持待补充。参考案例明确为场景参考。

页面：主页、公司介绍、企业文化、五类产品、21 个产品详情、工程展示、服务、资讯、4 个问题详情、联系页面与 sitemap。交互：可暂停轮播、键盘分类标签、手机导航、返回顶部、下载本地需求单。表单暂不发送至服务器。

验证：Astro 构建、生成页面链接及资源检查、桌面与手机浏览器截图、轮播/分类/表单下载交互检查。验证后关闭本任务的临时浏览器和服务器。
