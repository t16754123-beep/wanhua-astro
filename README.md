# 万华机房 / 亿华地板

使用 Astro 5 构建，以 https://www.czsrfloor.com/ 为参考的中文企业网站。保留参考首页的模块顺序、蓝白配色、桌面尺寸及产品图片，重新实现响应式布局与轻量交互。子页面采用统一的 Astro 模板，并非旧 CMS 的完整迁移。

## 本地使用

安装 Node.js 22 或以上，然后在本目录运行：

```sh
npm install
npm run dev
```

生产构建：`npm run build`，输出目录为 `dist`，可部署到支持静态文件的托管服务。页面链接使用 `.html` 后缀。

## 修改内容

- Logo：`public/assets/logo.png`，保留上传原图。
- 公司完整介绍：`src/data/intro.txt`，直接来自用户提供的文件。
- 产品分类、产品图与问题：`src/data/catalog.json`。
- 导航与页脚：`src/layouts/Layout.astro`。
- 首页：`src/pages/index.astro`。
- 页面模板：`src/pages/[...path].astro`。
- 响应式样式：`src/styles/site.css`。

包含 39 个 HTML 页面（含 404）、21 个产品详情与网站地图。首屏图片优先加载，其余图片延迟加载；无需前端框架运行时。

## 交付边界

未提供的万华电话、邮箱和详细地址标为待补充。需求表单可校验、生成并下载文本需求单，未连接邮件或后台收件服务，不会冒充发送成功。参考站的企业名称、电话、备案、统计和客服脚本均未沿用。含旧电话、产能或年限的宣传图不在页面使用。

产品和工程图片来自用户指定的参考站；工程图片已注明仅为场景参考，不代表万华客户项目。上线对外宣传前可用万华自己的工程素材替换。资讯详情目前使用参考首页摘要，未搬迁原站全部文章或产品技术参数。

## 验证

`npm run build` 检查 Astro 编译。`scripts/qa.cjs` 使用本机已有 Playwright/Chrome，检查页面链接与资源、企业信息替换、手机溢出、分类切换、轮播及需求单下载；`qa/` 保留桌面和手机检查截图。该脚本中的 Playwright 路径为当前机器路径，迁移后需调整。
